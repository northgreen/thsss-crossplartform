# Ownership diagnostic gate (2026)

- Build only this independent project: `dotnet build tests/testcase/ReplayPerformance/OwnershipChecks/OwnershipTool.csproj -c Release -warnaserror`. It uses pinned FodyHelpers 6.9.3 for Cecil, not the production weaver or game project.
- Let `TOOL=tests/testcase/ReplayPerformance/OwnershipChecks/bin/Release/net8.0/OwnershipTool.dll`. Run `dotnet "$TOOL" --self-test`, then `dotnet "$TOOL" INPUT.dll OUTPUT.dll`. Use an isolated diagnostic output directory; never production files or a live run directory. Output must not exist. The tool records input SHA256, checks it before writing, creates the output exclusively, and copies OwnershipProbe.dll beside it. Keep independent input/native/player hash and mtime checks around the complete Replay run.
- Before any instrumented game code executes, preload the copied helper with `Assembly.LoadFrom(Path.Combine(AppContext.BaseDirectory, "OwnershipProbe.dll"))`, then get `THSSS.Diagnostics.OwnershipProbe`. On Ready, call its static `Arm(stageData)` once on the game main thread. On Finish or caught failure, call `SaveReport(reportPath)`; it writes evidence before rejecting empty coverage or violations. The profiling harness opt-in is `THSSS_PROFILE_OWNERSHIP=1`; this tool does not enable or implement that harness hook. A fresh process is required for each arm/run.
- EnterFrame is injected at MainProcess entry, PresentState writes and update/render dispatch. Scope is the registered StageData only while the current state derives from Shooting.BaseStage. Loading/suspended states and unrelated/unpublished stages are excluded. Do not claim all world writes are main-thread-only. StageData reassignment checks both existing and assigned ownership.
- Enumerated BaseObject fields: OriginalPosition, StageData and Time backing fields; velocity, direction, angle, angleWithDirection, region, scaleLength, scaleWidth, scaleX, scaleY. Also StageDataPackage.BoundRect. All module field instructions for this set appear in OUTPUT.dll.ownership-manifest.json; stfld sites receive guards. BaseObject/derived Move and HitCheck entries and BaseObject target parameters receive call guards. Reading StageData for ownership uses reflection only; field reads are inventoried, not runtime read guards or a read-order equivalence proof.
- Unclassified ldflda uses and prefixed field writes fail closed. Recognized readonly address uses are immediate System.Drawing getters and the exact Rectangle.Equals pattern. The checked woven fixture had 49 writes, 33 methods and 7 state hooks, zero address gaps; these are observed counts, not universal golden constants. Inspect each new manifest.
- Reports require expectedThread, armedStage, positive frameObservations/scopedWrites/scopedCalls, zero violations and coverageNonempty/passed. Retain fieldWriteCounts, callCounts and firstViolation. Full Replay must additionally preserve key-aligned gameplay hashes and no-miss; self-tests do not establish that.
- Optional `dotnet "$TOOL" --smoke-copy OUTPUT.dll DEPENDENCY_DIRECTORY` exercises the actual guarded Time setter/early HitCheck without GUI and proves a forbidden worker write cannot mutate Time. Self-test artifacts stay under this project's bin directory; smoke reports stay beside the supplied diagnostic copy. Never regenerate numerical goldens here.
- Limits: selected module IL writes only, not arbitrary reflection/native writes or a race detector; observed active-stage ownership only, not arbitrary concurrent API, numerical, CPU-backend or alternate-architecture equivalence. Probe runs are not FPS benchmarks. Branch/switch execution is tested; EH boundary retargeting is structurally asserted, not a full exception-flow execution test.
